# InternCircle Task 3: Number Guessing Game & Word Counter

## Project Overview
This project contains two Python applications: a Number Guessing Game and a File-Based Word Counter. It demonstrates fundamental Python programming concepts, including loops, conditional statements, random number generation, file handling, and string manipulation.

## Features

### 1. Number Guessing Game
- Generates a random number between 1 and 100 using Python's `random` module.
- Allows users to guess the number until they find the correct answer.
- Provides hints such as "Too high" and "Too low".
- Tracks the number of attempts.
- Calculates a score based on the number of guesses.
- Handles invalid user input.

### 2. File-Based Word Counter
- Reads text from a user-specified file.
- Calculates the total number of words.
- Displays the frequency of each word.
- Uses regular expressions for word extraction.
- Uses Python's `Counter` class for word-frequency analysis.
- Handles missing files and file-reading errors.

## Technologies Used
- Python
- random module
- re module
- collections.Counter
- File handling and exception handling

## How to Run
1. Install Python on your computer.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

```bash
python main.py
```

5. Choose an option from the main menu.
6. To use the Word Counter, enter `sample.txt` or another text file located in the project folder.
